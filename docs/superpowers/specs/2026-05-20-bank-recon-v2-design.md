# 银行对账工具 v2.0 设计文档

**日期**: 2026-05-20  
**状态**: 设计完成  
**目标**: 独立 Win 桌面银行对账软件，支持自动匹配 + 手工确认 + 余额调节表 + 异常诊断

---

## 一、界面布局

左（60%）：银行余额调节表（主工作区）
右（40%）：诊断/明细/手工匹配 + 已匹配列表 + 导出

窗口可最大化（decorations: true, 带标准控制按钮 □ ✕ _）

---

## 二、银行余额调节表

### 2.1 结构

四栏双列：
```
银行对账单调节                  企业账面调节
  对账单余额         ¥X           账面余额         ¥X
  + 企业已收银行未收 (N)          ± 银行已收企业未收 (N)
    5/10 北京科技    ¥X ✓           5/14 利息     ¥X ✓
    5/15 广州建设    ¥X →线索→      5/20 不明     ¥X →线索→
  - 企业已付银行未付 (N)          ± 银行已付企业未付 (N)
    5/08 付货款      ¥X ✓           5/16 手续费   ¥X ✓
    5/11 付运费      ¥X →线索→      5/18 退款     ¥X →线索→
  ─────────────────               ─────────────────
  调节后银行余额     ¥502,000       调节后企业余额   ¥502,000
```

### 2.2 异常提示规则（内嵌，无横幅）

每条未匹配项后显示简洁线索：

| 场景 | 提示文字 |
|------|----------|
| 同金额多笔/可能漏做 | `可能漏做→点击排查` |
| 打款失败重付 | `重付未做回单→补凭证` |
| 银行已收企业未收 | `银行已收¥X 企业漏记→补收入` |
| 银行已付企业未付 | `银行已付¥X 企业未记→补支出` |

## 三、右侧操作区

### 3.1 诊断面板（点击左侧线索后显示）

```
┌─ 诊断 ────────────────────────────┐
│ 问题：企业已付¥5,000，银行3笔中有1笔无对应    │
│ 原因：打款失败退回重新支付，企业只做了一笔付款  │
│ 处理：补录退款入账+二次付款，共2张凭证         │
└───────────────────────────────────┘
```

文字简洁、专业术语，不写科普。

### 3.2 明细比对面板

企业科目明细表格：日期 | 凭证号 | 摘要 | 金额

银行流水表格：日期 | 收付款人 | 智能提取备注 | 金额

- 最不可能匹配项淡红底置顶
- 字体自适应：内容少 11px，内容多缩小至 9px
- 必要时换行，不截断

### 3.3 手工匹配

- 明细区每行前带复选框
- 勾选 N 条 → "确认手工匹配 (N)" → 写入匹配记录
- 确认后从调节表移除，余额实时重算
- 批量操作：高置信度项预勾选

### 3.4 已匹配列表

折叠滚动列表，显示格式：`5/10 北京科技 ¥X = 北京科技 ¥X`

### 3.5 操作按钮

- 导出 Excel 报告（CSV，含调节表全量数据）
- 重新匹配（清空结果重新跑引擎）

## 四、匹配引擎

4 轮自动匹配：精确 → 容差(0.5元) → 跨期(90天) → 摘要匹配

输出字段：
- matched: 已匹配列表
- unmatched_book: 未匹配科目明细
- unmatched_bank: 未匹配银行流水
- 每笔含：日期/金额/凭证号/摘要/收付款人/对方户名

### 4.1 同金额标记

匹配完成后扫描同金额未匹配组（科目侧N笔对应银行侧M笔，N≠M）：
- 标记为异常，在调节表显示线索
- 点击后右侧展示双方完整明细

### 4.2 智能备注提取

从银行流水摘要/备注列提取：
- 收付款方（公司名/人名）
- 用途关键词
- 退款标记（含"退""返""冲"等字）

### 4.3 退款重付检测

检测模式：同一客户/金额，银行流水有 +A → -A → -A 三笔，科目明细只有一笔 -A
- 标记为"重付未做回单→补凭证"
- 右侧诊断写明缺失的凭证
